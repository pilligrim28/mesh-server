# MaxPulse — Arduino Pro Micro + MAX30102 → ПК по COM-порту

Скетч для Pro Micro (ATmega32U4) + приложение `pulse-com`, которое читает датчик по USB,
показывает пульс/SpO₂/пульсовую волну в браузере и пишет **каждую сессию в отдельные CSV**.

## Подключение

| MAX30102 | Pro Micro |
|----------|-----------|
| SDA      | 2 (SDA)   |
| SCL      | 3 (SCL)   |
| VIN      | VCC       |
| GND      | GND       |

Пины 2/3 на Pro Micro — это аппаратный I²C, ничего переназначать не нужно.

> Pro Micro 5 В / 16 МГц: у большинства модулей MAX30102 (фиолетовые/зелёные платки) есть свой
> стабилизатор 1,8/3,3 В и подтяжки — их можно питать от VCC. Если датчик не находится
> (`ERR,SENSOR_NOT_FOUND`), проверьте пайку SDA/SCL и что подтяжки на модуле идут к 3,3 В;
> на «голых» модулях без стабилизатора нужен преобразователь уровней.

## Прошивка

**Arduino IDE:** откройте `MaxPulse/MaxPulse.ino`, установите библиотеку
*SparkFun MAX3010x Pulse and Proximity Sensor Library* (Менеджер библиотек),
плата **Arduino Leonardo** (для Pro Micro 5 В/16 МГц; для 3,3 В/8 МГц — плата SparkFun Pro Micro 8 MHz),
выберите порт → «Загрузить».

**PlatformIO:** `pio run -e promicro16 -t upload` (или `-e promicro8`).

**Готовый hex:** `firmware.hex` можно залить `avrdude -p atmega32u4 -c avr109 -P COM5 -U flash:w:firmware.hex`
(сразу после двойного нажатия RST — плата 8 с в загрузчике, порт может смениться).

Проверка: монитор порта (любая скорость), отправьте `PING` → `HELLO,MAXPULSE,1.0`.

## Приложение pulse-com

Windows: запустите `pulse-com.exe` — плата найдётся сама, откроется браузер `http://127.0.0.1:8081`.
Linux: `./pulse-com` (нужен доступ к `/dev/ttyACM0`: `sudo usermod -aG dialout $USER`, перелогиниться).

```
pulse-com                    автопоиск платы
pulse-com -port COM5         конкретный порт (Linux: /dev/ttyACM0)
pulse-com -label "Иван"      метка первой сессии
pulse-com -dir D:\pulse      куда писать CSV (по умолчанию папка data рядом с exe)
pulse-com -no-autorec        не начинать запись при запуске
pulse-com -addr 0.0.0.0:8081 открыть интерфейс для других устройств в сети
pulse-com -list              список COM-портов
pulse-com -sim               без железа: встроенный эмулятор Arduino
```

Закройте монитор порта Arduino IDE перед запуском — COM-порт может занять только одна программа.

### Файлы

Кнопка «Новая сессия» (с меткой, например именем человека) закрывает текущие файлы и начинает новые:

| Файл | Содержимое |
|------|------------|
| `session_20260801_153000_Иван.csv`       | время; мс_устройства; палец; пульс; SpO₂; IR; Red — раз в 0,25–5 с |
| `session_20260801_153000_Иван_beats.csv` | каждый удар: время; мс; мгновенный пульс; интервал между ударами, мс |
| `session_20260801_153000_Иван_raw.csv`   | сырой сигнал 100 Гц (только когда включены «Сырые данные») |

Разделитель `;`, кодировка UTF-8 с BOM — открываются в Excel двойным щелчком. Пустая ячейка
пульса/SpO₂ = значение ещё не измерено (палец не приложен или сигнал неустойчив).
Данные сбрасываются на диск каждую секунду, так что при выдёргивании кабеля теряется не больше секунды.
При отключении платы приложение ждёт и переподключается само, запись продолжается в те же файлы.

## Протокол (текст, строки `\n`)

Arduino → ПК:

```
HELLO,MAXPULSE,1.0                        приветствие (при старте и на PING)
D,<мс>,<палец>,<пульс>,<SpO2>,<IR>,<RED>  сводка раз в RATE мс (0 = нет значения)
B,<мс>,<пульс>                            каждый удар
R,<мс>,<IR>,<RED>                         сырой сигнал 100 Гц (RAW ON)
S,<run>,<raw>,<rate>,<led>,<temp*10>      состояние (на STATUS)
OK,<команда> | ERR,<причина>
```

ПК → Arduino: `PING | STATUS | START | STOP | RAW ON | RAW OFF | RATE <200..10000> | LED <0..255>`

SpO₂ считается упрощённо (отношение R по пульсациям IR/Red) — для наблюдения тенденций, не для диагностики.
